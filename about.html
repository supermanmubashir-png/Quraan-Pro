🕌 Quraan-Pro

Modern • Fast • Beautiful Qur’an Experience

Quraan-Pro is a powerful Progressive Web App designed to deliver a smooth, distraction-free Qur’an reading experience. It is built with performance, simplicity, and accessibility in mind.

📖 About the Project

Quraan-Pro is designed to replicate a real mobile Qur’an application inside the browser. It focuses on speed, usability, and offline-friendly design. It combines multiple Islamic tools into a single unified platform.

✨ Core Features Overview

  • Full Qur’an navigation (Surah → Ayah level access)
  • Beautiful Arabic rendering system
  • Optional translation support
  • Audio playback system with multiple reciters
  • Favorites system for saving ayahs
  • Advanced settings panel
  • Progressive Web App support
  • Offline caching via service worker

📖 Reading System

The reading system is designed for clarity and comfort. Each Surah is structured with proper spacing and clean typography.

Features include:
  • Auto-loaded Surah content
  • Scroll-based navigation
  • Clickable ayahs
  • Optional translation display
  • Custom font sizing support
  • Responsive layout for mobile devices

🎧 Audio Engine

The audio system supports multiple reciters and flexible playback options.

Capabilities:
  • Play individual ayahs
  • Continuous Surah playback
  • Speed adjustment control
  • Repeat / loop functionality
  • Pause delay customization
  • Auto next ayah system

🧠 Tajweed System

Tajweed mode helps users identify correct pronunciation rules visually.
  • Toggle ON/OFF anytime
  • Color-coded highlighting
  • Improves recitation learning
  • Lightweight implementation

⭐ Favorites System

Favorites allow users to bookmark important ayahs for quick access later.

System features:
  • Multi-ayah bookmarking
  • Persistent local storage
  • Quick access panel
  • Instant navigation to saved ayahs
  • Easy remove functionality

🎨 UI & Themes

Quraan-Pro includes multiple visual themes designed for comfort and readability.
  • Dark mode optimized for night reading
  • Light mode for daytime use
  • Kaaba-inspired premium theme
  • Smooth glass-style UI elements
  • Responsive layout system

⚙ Settings System

The settings system allows full personalization of the app experience.
  • Audio configuration controls
  • Reciter selection system
  • Font size customization
  • Translation toggle system
  • Tajweed activation
  • Loop and playback settings
  • Saved preferences using localStorage

🧭 Islamic Tools

Additional tools are included to support daily Islamic practice.
  • Qiblah direction compass
  • Prayer-related utilities
  • Quick access buttons

📱 Progressive Web App (PWA)

Quraan-Pro is fully installable like a native application.

Features:
  • Add to home screen support
  • Offline caching system
  • Fast loading performance
  • App-like full-screen mode

🚀 Performance Design

The app is optimized for low memory usage and fast rendering.
  • Lightweight JavaScript
  • Efficient DOM updates
  • Minimal dependencies
  • Cached resources via service worker

📊 Future Improvements

Planned enhancements for future versions:
  • Advanced search system
  • Offline full audio download
  • AI-based memorization mode
  • Cloud sync for bookmarks
  • Multi-language UI support

🧑‍💻 Developer Note

Quraan-Pro is built with a focus on simplicity and accessibility. It avoids heavy frameworks to ensure fast performance on all devices, especially low-end mobile phones.

📜 Philosophy

The goal of this project is to make Qur’an reading digitally accessible, clean, and distraction-free while maintaining a respectful and user-friendly interface.
