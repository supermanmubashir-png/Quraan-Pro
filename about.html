🕌 Quraan-Pro

Quraan-Pro is a modern Progressive Web App designed for a smooth and focused Qur’an reading experience on mobile and desktop.

✨ Features

  • 📖 Full Qur’an browsing (Surah → Ayah)
  • 🎧 Audio playback with reciters
  • 🧠 Tajweed mode
  • ⭐ Favorites system
  • 🎨 Themes & UI customization
  • ⚙️ Advanced settings
  • 📱 Installable PWA

🎧 Audio

  • Play ayah
  • Speed control
  • Loop / repeat
  • Auto next

⭐ Favorites

  • Bookmark multiple ayahs
  • Quick access panel
  • Tap to jump

🎨 UI

  • Dark / Light themes
  • Kaaba theme
  • Responsive design

📱 PWA

  • Install as app
  • Offline support
  • Fast loading

🚀 Tech

  • HTML, CSS, JavaScript
  • Service Worker
  • LocalStorage
  • GitHub Pages
