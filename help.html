📖 Quraan Pro Help Center

📌 Overview

This app helps you read, listen, and understand the Holy Qur’an with multiple tools.

☰ Navigation

  • ☰ opens Surah list
  • Tap any Surah to open it
  • Search bar filters Surahs instantly

🎧 Audio System

  • ▶ Play ayah
  • 🔁 Loop ayah
  • ⏭ Continue next ayah
  • Speed control available in settings

⭐ Bookmark System

  • Tap ⭐ to save ayah
  • All saved ayahs appear in ⭐ panel
  • Tap to jump directly

📘 Tafseer

  • Tap 📘 to load explanation
  • Shows meaning of ayah
  • Can be opened/closed anytime

🎯 Go To Feature

  • Enter Surah number
  • Enter Ayah number
  • Jump directly

⚙ Settings

  • Change Reciter (e.g. :contentReference[oaicite:0]{index=0})
  • Change Translation
  • Adjust speed, repeat, delay

🕌 Prayer Times

Shows Hanafi-style prayer timings using API.

🧭 Qiblah Compass

  • Uses device sensor
  • Points direction to Makkah
  • Needs permission

📱 Installation

  • Tap install button
  • Adds app to home screen
  • Works like native app

⚠ Tips

  • Use HTTPS for full features
  • Allow permissions for compass
  • Refresh if audio not working

🔧 Troubleshooting

  • Install not showing → refresh page
  • Audio not playing → tap again
  • Blank screen → clear cache
