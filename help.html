📖 Quraan Pro Help Center

📌 Introduction

Quraan Pro is a complete Quran reading, listening, and learning app with modern features.

This help guide explains every feature in detail.

☰ Navigation

  • Tap ☰ to open Surah list
  • Select any Surah
  • Use search to find quickly
  • Sidebar auto closes

🔍 Search

  • Type Surah name
  • Instant filtering
  • Works in real time

🎧 Audio System

  • ▶ Play ayah
  • 🔁 Loop ayah
  • ⏭ Continue next ayah
  • Adjust speed
  • Repeat count
  • Delay between ayahs

🧠 Tajweed

  • Toggle tajweed colors
  • Helps correct recitation
  • Highlights rules visually

⭐ Bookmarks

  • Tap star to save ayah
  • Tap again to remove
  • View all in star panel
  • Tap to jump

📘 Tafseer

  • Tap 📘 under ayah
  • Loads explanation
  • Tap again to close

⚙ Settings

  • Change reciter
  • Change translation
  • Adjust speed
  • Theme selection
  • Resume feature

🎨 Themes

  • Dark mode
  • Light mode
  • Blue, green, purple themes
  • Kaaba gold theme

🧭 Qiblah Compass

  • Uses phone sensors
  • Points to Kaaba
  • Requires permission

🕌 Prayer Times

  • Shows daily times
  • Based on Hanafi method
  • Requires internet

📱 Install App

  • Tap install button
  • Add to home screen
  • Works like native app

⚡ Performance Tips

  • Use stable internet
  • Refresh if lag
  • Close unused tabs

🛠 Troubleshooting

  • Audio not playing → tap again
  • Install not showing → refresh
  • Compass not working → allow sensors

❓ FAQ

Q: Why audio stops?
A: Network issue

Q: Why app slow?
A: Low device memory

📚 Advanced Tips

  • Use loop for memorization
  • Bookmark important ayahs
  • Use tafseer for learning
