📖 Quraan Pro Help Center

📌 Introduction

Quraan Pro is a modern Qur’an app designed for reading, listening, and understanding.

This guide explains every feature in detail.

☰ Sidebar Navigation

  • Tap ☰ to open all Surahs
  • Tap any Surah to load it
  • Sidebar auto closes after selection
  • Scroll to browse all 114 Surahs

🔍 Search System

  • Type Surah name (e.g. Baqara)
  • Results filter instantly
  • Works in real-time

🎧 Audio Controls

  • ▶ Play ayah
  • 🔁 Loop ayah continuously
  • ⏭ Continue to next ayah
  • Speed control in settings
  • Repeat count available
  • Delay between ayahs supported

⭐ Bookmark System

  • Tap ⭐ to save any ayah
  • Tap ⭐ again to remove
  • All saved ayahs appear in star panel
  • Tap any saved ayah to jump

📘 Tafseer Feature

  • Tap 📘 under any ayah
  • Loads explanation of ayah
  • Tap again to close
  • Loads only when needed (fast)

🎯 Go To Feature

  • Enter Surah number
  • Enter Ayah number
  • Tap Go to jump directly

⚙ Settings Panel

  • Change Reciter (e.g. Abdul Rahman Al-Sudais)
  • Change Translation
  • Adjust speed, repeat, delay
  • Resume last ayah

🌍 Translation System

  • Supports multiple languages
  • Switch from settings
  • Displayed below Arabic text

🧠 Tajweed Mode

  • Toggle using 🧠 button
  • Highlights rules (basic)
  • Improves recitation accuracy

🕌 Prayer Times

  • Uses online API
  • Shows daily timings
  • Based on Hanafi method

🧭 Qiblah Compass

  • Uses device sensors
  • Points toward Makkah
  • Requires permission

📱 Install App

  • Tap 📱 button
  • Add to home screen
  • Works like real app

💾 Offline Mode

  • Basic offline support via cache
  • Works after first load
  • Audio requires internet

⚡ Performance Tips

  • Use stable internet
  • Avoid opening too many tabs
  • Reload if lag occurs

🛠 Troubleshooting

  • Audio not playing → tap again
  • Install not working → refresh page
  • Blank screen → clear cache

❓ FAQ

Q: Why audio stops?
A: Network issue or browser restriction.

Q: Why install not showing?
A: Already installed or criteria not met.

Q: Why compass not accurate?
A: Sensor permission needed.

📚 Learning Tips

  • Use loop for memorization
  • Use tafseer for understanding
  • Bookmark important ayahs

🔒 Permissions

  • Location → prayer + compass
  • Motion → compass direction
  • Audio → recitation

📌 Advanced Usage

  • Combine loop + repeat for memorization
  • Use resume for daily reading
  • Use go-to for quick navigation

🏁 Conclusion

This app combines reading, listening, and learning tools into one platform.

Use it daily for best experience.
