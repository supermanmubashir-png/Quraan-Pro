🕌 Quraan-Pro

Quraan-Pro is a modern, lightweight Progressive Web App (PWA) designed for a smooth and focused Qur’an reading experience on both desktop and mobile devices.

It combines clean UI, powerful features, and offline capability to feel like a real app — directly in your browser.

✨ Features

📖 Reading Experience
Full Qur’an browsing (Surah → Ayah)
Clean and minimal UI for distraction-free reading
Smooth scrolling and navigation
Arabic text display with adjustable font size
Optional translation support

🎧 Audio Playback
Play individual ayahs
Multiple reciters support
Playback speed control
Loop / repeat ayah feature
Pause control between ayahs
Auto-play next ayah

🧠 Tajweed Mode
Toggle Tajweed highlighting
Helps in correct pronunciation
Clean visual indicators

⭐ Favorites System
Bookmark multiple ayahs
Favorites panel for quick access
Tap to jump directly to saved ayah
Persistent storage using localStorage

🧭 Islamic Tools
Qiblah direction (compass)
Prayer (Namaz) feature integration

🎨 UI & Customization
Multiple themes (including Kaaba-style theme)
Light / Dark mode support
Responsive design (mobile + desktop)
Smooth panel system (settings, help, favorites)

⚙️ Settings System
Audio controls (speed, loop, auto-next)
Reading preferences (font size, translation toggle)
Theme selection
Tajweed toggle
Persistent settings (saved locally)

📱 Progressive Web App (PWA)
Installable on mobile like a real app
Offline support (via service worker)
Fast loading and caching
Works across devices

🆘 Help & Updates
Dedicated Help page
Updates page with version history
Easy access from app UI

🚀 Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
LocalStorage API
Service Workers (PWA)
GitHub Pages (Hosting)
